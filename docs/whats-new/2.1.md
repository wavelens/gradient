## UX Improvements
icon: auto_awesome

Navigation is faster and easier to read.

- Live Jobs show running jobs with project, task and worker.
- Press `Ctrl+K` or `/` to open the command palette and jump to a project, task, or cache.
- Build logs have an attempt selector, with a separate log for each attempt.
- The **Readiness** card on a project page can show when Workers, a writable cache, or Git access are missing.
- The separate access pages give way to one member page.

## Gradient Exec
icon: terminal

Run programs in a virtual machine on a worker, outside the Nix sandbox.

- Turn exec on or off for each task.
- Choose the guest size and work disk. Prepare pre-warmed guests ahead of time.
- Start the exec job automatically after the program build is complete. Distribute guests across a multi-node cluster.
- Use custom exec images.
- Use `gradient run` to start a program. Use `-L` to forward a local port.

## Multi-Node Evaluations
icon: hub

Tasks that enable multi-node evaluations split large evaluations across workers.

Cost estimates drive the scheduler to split an evaluation into shards. Workers evaluate shards in parallel, so large flakes finish faster.

## SBOMs
icon: inventory_2

Every successful build has a software bill of materials (SBOM).

- Download the document as CycloneDX JSON from the **SBOM** entry in the build menu.
- The API can serve the same document.

## Admin Area
icon: admin_panel_settings

Server administrators can access the Admin Area.

- Tabs for **Overview**, **Workers**, **Storage**, **Git hosts**, and **Settings**.
- Use **Enable Draining** to stop new evaluations and builds from starting on the whole instance. Use **Drain** on the Workers tab to stop one worker from taking new work.
- Use **Run Deep GC** to delete stored files that no record in the database references.

## Pinned Cache Paths
icon: push_pin

Keep packages in the cache through garbage collection.

- Pin or unpin a package in the list of packages in the cache.
- Pin everything that the package references when needed and keep release artifacts installable.
- Filter the list by pin status.
