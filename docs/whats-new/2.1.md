## Restricted Evaluation
icon: lock

Evaluations use Nix `restrict-eval`. Fetches during evaluation can reach only inputs locked by `flake.lock` and allowed URL prefixes.

- Existing projects have restrictions after an upgrade.
- Add URL prefixes per project in project settings, or server-wide with `GRADIENT_EVAL_ALLOWED_URI_PREFIXES`.
- Clear, in project settings, **Restrict fetches during evaluation to locked flake inputs and allowed URL prefixes** to turn off per-project restrictions.
