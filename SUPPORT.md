# Support

## Community

- Questions and help on [Matrix](https://matrix.to/#/#gradient-ci:matrix.org).
- Bugs and feature requests as [GitHub issues](https://github.com/wavelens/gradient/issues/new/choose).
- Vulnerabilities only through the [Security Policy](./SECURITY.md).

## Releases

- Version numbers follow [Semantic Versioning](https://semver.org).
- Breaking changes to the NixOS module, the API, the worker protocol or the database schema wait for a new major version.
- Every release can migrate the previous one in place.
- Fixes land on `main` and in the latest release.

## Long-Term Support

Older releases get long-term support on request. Wavelens can keep a chosen release line on security and critical fixes for an agreed period.

## Commercial Support

Wavelens GmbH can provide paid support for companies running Gradient.

- Long-term support for a chosen release.
- Guaranteed response times.
- Help with deployment, upgrades and scaling.
- A commercial license as an alternative to the AGPL.

Contact info@wavelens.io.
